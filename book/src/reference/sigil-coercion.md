# Sigil coercion and `EncodeAs`

The `&` prefix on a field-level `enc` path - `#[klv(enc = &encb::u8)]` - is the
**sigil coercion** form. This page explains what it means, why it exists, and
when to use each form.

## Why the sigil exists

The [`EncodeValue`](./traits.md) trait is defined as:

```rust,ignore
pub trait EncodeValue<O> {
    fn encode_value(&self) -> O;
}
```

`&self` gives the derive macro access to each field by reference. So when the
macro emits the per-field encode call, it has `&field_value` in hand.

Now look at the two shapes of encoder function you can plug in:

1. **Borrowed-form encoders** already take a reference:

   ```rust,ignore
   fn my_encoder(input: &InnerValue) -> Vec<u8> { ... }
   ```

   `&field_value` matches `&InnerValue` directly. No coercion needed.

2. **Owned-form encoders** - which is how the built-in primitive encoders in
   [`tinyklv::codecs::binary::enc`](./codecs.md) are written - take the value
   by value:

   ```rust,ignore
   pub fn u8(x: u8) -> Vec<u8> { ... }
   pub fn be_u16(x: u16) -> Vec<u8> { ... }
   ```

   Passing `&u8` to `fn u8(x: u8)` is a type error. We need a bridge.

The `&` sigil is that bridge. It tells the macro: *this encoder expects a
by-value (or cheaply-borrowed) argument; route the field through `EncodeAs`
first, then call the encoder on the resulting value.*

## The two forms

| Syntax | Encoder signature | Dispatch |
|---|---|---|
| `#[klv(enc = path)]` | `fn(&T) -> O` | call `path(&self.field)` |
| `#[klv(enc = &path)]` | `fn(T::Borrowed) -> O` | call `path(EncodeAs::encode_as(&self.field))` |

### No sigil - direct borrow

Use this when your encoder already takes `&T`. Any encoder generated by
`#[derive(Klv)]` falls in this bucket, because `EncodeValue::encode_value`
takes `&self`:

```rust,ignore
#[klv(
    key = 0x04,
    dec = GpsFix::decode_value,
    enc = GpsFix::encode_value,  // &GpsFix -> Vec<u8>, no sigil needed
)]
gps: GpsFix,
```

### With sigil - `EncodeAs` bridge

Use this when your encoder takes `T` by value. All primitive encoders under
`tinyklv::codecs::binary::enc` fit here:

```rust,ignore
#[klv(key = 0x02, dec = decb::be_u16, enc = &encb::be_u16)]
temperature_centideg: u16,
```

Under the hood the macro generates (simplified):

```rust,ignore
encb::be_u16(EncodeAs::encode_as(&self.temperature_centideg))
```

For primitives `EncodeAs::encode_as(&u16)` is just `*self` - a `Copy` - so this
compiles down to a plain function call with zero overhead. Note that, although it 
may seem counter-intuitive to use a `&` in order to `Copy` a value, under the hood
a `Copy` would have already been performed 

## The `EncodeAs` trait

```rust,ignore
pub trait EncodeAs {
    type Borrowed<'a> where Self: 'a;
    fn encode_as(&self) -> Self::Borrowed<'_>;
}
```

Built-in implementations:

| Input type | `Borrowed<'a>` | Behaviour |
|---|---|---|
| `u8`..`u128`, `i8`..`i128`, `f32`, `f64`, `bool`, `char`, `usize`, `isize` | `Self` | copy by value |
| `String` | `&'a str` | borrow as `&str` |
| `Vec<T>` | `&'a [T]` | borrow as slice |
| `Cow<'_, str>` | `&'a str` | unwrap to `&str` |
| `Cow<'_, [T]>` | `&'a [T]` | unwrap to slice |
| `Box<T>`, `Rc<T>`, `Arc<T>` | `&'a T` | deref to inner |

Every conversion is zero-cost: no clones, no allocations. `Copy` scalars pass
by value because that's already free; owned containers coerce to their
natural borrowed counterpart.

## When to implement `EncodeAs` yourself

You don't need to - for custom structs, just use the no-sigil form and point
`enc` at a function that takes `&YourType`. The derive-generated
`YourType::encode_value` already has that signature.

Implement `EncodeAs` on your own type **only** when:

- You want your type to work with the `&` sigil form, AND
- You want the encoder to receive some borrowed view distinct from `&Self`
  (e.g. a newtype over `String` that should coerce to `&str`).

This is rare. Most codebases never touch `EncodeAs` directly.

## Where the sigil is accepted

The `&` sigil is a **field-level** construct. It is currently not accepted
inside container-level `default(...)` blocks - if you need a fallback encoder
for a family of fields, place the encoder on each field explicitly instead of
relying on a container-level default.

## Summary

- `enc = path` - encoder takes `&T`, field is borrowed directly.
- `enc = &path` - encoder takes `T`, field is routed through `EncodeAs`.
- Use the no-sigil form for custom types whose encoders take `&Self`
  (including all `#[derive(Klv)]`-generated `encode_value` methods).
- Use the sigil form for the built-in primitive encoders in
  `tinyklv::codecs::binary::enc`.
