# Traits

The `tinyklv::prelude::*` import re-exports every trait anonymously
(`as _`) so the method calls work without polluting your namespace.
This page documents each trait directly.

## `EncodeValue<O>`

```rust,ignore
pub trait EncodeValue<O> {
    fn encode_value(&self) -> O;
}
```

Emits the KLV triples for this value (no sentinel, no frame length).
Generated by `#[derive(Klv)]` unless `allow_unimplemented_encode` is
set.

## `EncodeFrame<O>`

```rust,ignore
pub trait EncodeFrame<O> {
    fn encode_frame(&self) -> O;
}
```

Emits a full packet: `sentinel + length + <encode_value output>`.
Only generated when the container declares `sentinel = ...`.

## `DecodeValue<S>`

```rust,ignore
pub trait DecodeValue<S> {
    fn decode_value(input: &mut S) -> winnow::Result<Self>
    where
        Self: Sized;
}
```

Parses a KLV triple stream until the container's field set is
satisfied (or the stream is exhausted, depending on
`deny_unknown_keys`).

## `DecodeFrame<S>`

```rust,ignore
pub trait DecodeFrame<S> {
    fn decode_frame(input: &mut S) -> winnow::Result<Self>
    where
        Self: Sized;
}
```

Seeks the sentinel, reads the frame length, subslices the stream to
exactly that many bytes, and calls `decode_value` on the subslice.

## `SeekSentinel<S>`

```rust,ignore
pub trait SeekSentinel<S> {
    fn seek_sentinel(input: &mut S) -> winnow::Result<()>;
}
```

Advances the stream to the position immediately *after* the next
occurrence of the sentinel. Uses `memchr` internally for efficiency.

## `RepeatedDecode<S>`

Used internally by fields carrying `#[klv(repeated)]`. You rarely
invoke it directly; `Vec<T>` fields get the behavior for free.

## `BreakCondition<S>`

The user-extensible stop predicate for repeated decode. A blanket
implementation covers the common cases; override only when you need
custom termination logic (see the
[Custom Break Conditions](../tutorials/14-break-condition.md) tutorial).

## `IntoKlv<O>`

Marker trait emitted by built-in codecs. Codec authors implement it
on their output types. Application code does not touch it directly.
