# Traits

`use tinyklv::prelude::*` brings every trait into scope so the method
calls work.

## Decode traits

### `DecodeValue<S>`

```rust,ignore
pub trait DecodeValue<S>: Sized
where
    S: winnow::stream::Stream,
{
    fn decode_value(input: &mut S) -> crate::Result<Self>;
}
```

Parses KLV items into `Self`. Generated by `#[derive(Klv)]` unless a decoder is
missing, which `allow_unimplemented_decode` allows. A blanket impl decodes a
`Vec<T>` by repeating `T` until one fails or consumes nothing (a zero-sized `T`
does not compile); `T::drain_frames` repeats `decode_frame` over sentinel-framed
packets. See
[Tutorial 13 - Repeated extraction](../tutorial/advanced/13-repeated-extraction.md).

### `DecodePartial<S>`

```rust,ignore
pub enum Packet<T, P>
where
    P: Partial<Final = T>,
{
    Ready(T),
    NeedMore(P),
}

pub trait DecodePartial<S>: Sized
where
    S: winnow::stream::Stream,
{
    type Partial: Default + Partial<Final = Self>;
    fn decode_partial(
        input: &mut S,
    ) -> Result<Packet<Self, Self::Partial>, PartialError>;
}
```

The streaming companion of `DecodeValue`, also derived:

| Variant | Meaning |
|---------|---------|
| `Ready(t)` | The decode loop ended first, at a `break_on` stop say, and finalized `t`. |
| `NeedMore(p)` | The input ran out, even with every field in; `p` holds the fields decoded so far, the cursor at the start of any cut item. |

`Err` is a `tinyklv::traits::PartialError`: `kind()` is its `ErrorKind`,
`label()` names what was rejected, and `Display` prints the label. A caller
that knows the body is complete after a `NeedMore(p)` calls `p.finalize()`.

### `Partial`

```rust,ignore
pub trait Partial: Sized {
    type Final;
    fn finalize(self) -> Result<Self::Final, PartialError>;
}
```

`#[derive(Klv)]` generates `<Name>PartialPacket`, the struct with every KLV
field an `Option<T>`; `finalize()` checks that the required ones are in and
yields the struct. `TryFrom<Partial> for T` is generated too, so
`partial.try_into()` needs no `Partial` import.

### `ResumePartial<S>` (internal)

`T::resume_partial(&mut input, partial)` continues a decode from a saved
`NeedMore(partial)`; `decode_partial` is it from a default partial.

### `Decoder<P, S>`

```rust,ignore
pub struct Decoder<P, S> { /* owned Vec<u8> buffer + optional partial */ }

impl<P, S> Decoder<P, S> {
    pub fn new() -> Self;
    pub fn with_capacity(cap: usize) -> Self;
    pub fn feed(&mut self, bytes: &[u8]);
    pub fn buffered(&self) -> &[u8];
    pub fn partial(&self) -> Option<&P>;
    pub fn into_partial(self) -> Option<P>;
    pub fn clear(&mut self);
    pub fn iter(&mut self) -> DecoderIter<'_, P, S>;
    pub fn next<T>(&mut self) -> Option<T>;
}

impl<P, T> Decoder<P, &[u8]>
where
    P: Partial<Final = T> + Default,
{
    pub fn finish(self) -> Result<T, DecodeIterError>;
}
```

Buffered streaming for a `T` with a `sentinel`, which marks where each packet
starts in a continuous stream. `feed` appends bytes from a socket, file or ring
buffer; `next` and `iter` find each packet and, once its body is all buffered,
decode it one-shot with `decode_value`. A packet still arriving stays in the
buffer for a later `feed`: this fresh mode stores no partial. Resume mode, which
continues one, is entered only by calling `PartialIterator::next_resume`.

| `next()` | Meaning |
|--------|---------|
| `Some(t)` | A packet decoded; its bytes are drained. |
| `None` | No packet is all buffered yet, or the one reached was malformed and is drained; `next_fresh()` tells them apart. |

`finish(self)` finalizes the stored partial, in fresh mode an empty one, so a
struct with a required field gets `Err(Malformed(..))` of kind
`MissingRequired`. At the end of a stream, check `buffered()` for a cut packet
instead. `DecodeIterError` variants: `Eof`, `NeedMore`,
`Malformed(ContextError)`.

To branch on why a decode failed, match `tinyklv::ErrorKind`, not the text:
`ErrorKind::of(&err)` reads a one-shot `ContextError`, `DecodeIterError::kind()`
a `Decoder` error, each `None` when untagged. The kinds are `Truncated`,
`MalformedValue`, `WrongLength`, `NoProgress`, `UnknownKey`, `MissingRequired`,
`Aborted` and `MissingSentinel`; the enum is `#[non_exhaustive]`, so keep a `_`
arm.

See [Tutorial 15 - Streaming partial packets](../tutorial/advanced/15-streaming-decode.md).

### `DecodeFrame<S>`

```rust,ignore
pub trait DecodeFrame<S>: Sized
where
    S: winnow::stream::Stream,
{
    fn decode_frame(input: &mut S) -> crate::Result<Self>;
}
```

A blanket impl over `SeekSentinel + DecodeValue`. The derive generates
`SeekSentinel` for a struct with a `sentinel`: it finds the sentinel, reads the
packet length and returns the body, which `decode_frame` decodes with
`decode_value`.

## Encode traits

### `EncodeValue`

```rust,ignore
pub trait EncodeValue {
    fn encode_value(&self, out: &mut Vec<u8>);
}
```

Appends this value's KLV bytes to `out` (no sentinel, no packet length).
Generated by `#[derive(Klv)]` unless an encoder is missing, which
`allow_unimplemented_encode` allows.

### `EncodeFrame`

```rust,ignore
pub trait EncodeFrame {
    fn encode_frame(&self, out: &mut Vec<u8>);
}
```

Appends a full packet to `out`: `sentinel + length + <encode_value bytes>`.
Only generated when the container declares `sentinel = ...`.

How the `&` sigil routes a field reference to an encoder:

## Control: `break_on` and `BreakType`

Loop control is a container attribute, not a trait: `#[klv(break_on = ..)]`
runs right after each key, in `decode_value`, `decode_frame` and the
`decoder()` alike
([`break_on`](./container-attributes.md#break_on--key-literal--path)). A key
literal is `Done` on a key that compares equal to it
([leaving its length](./limits.md#a-literal-leaves-the-terminators-length)); a
fn returns a `BreakType`:

| Variant | Meaning |
|---------|---------|
| `Proceed` | Decode the item from just after the key (default) |
| `Skip` | Continue the loop where the fn left the input; under `keylen`, one that read nothing steps over a `Sliced` value, or ends the loop after an `Inline` header |
| `Done` | Stop looping, return accumulated fields, after the same `keylen` step-over |
| `Abort(&'static str)` | Stop looping, return `Err` labelled with the message |

See [Tutorial 14 - Break conditions](../tutorial/advanced/14-break-condition.md).
